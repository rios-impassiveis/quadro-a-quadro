# Quadro a Quadro

Transforme suas fotos em cenas de filme, com aquela legenda amarela clássica.

Junte várias imagens numa tirinha. Todos os quadros saem na mesma proporção de cinema, então até fotos que não vieram de filme parecem cenas de um. Depois é só baixar no tamanho certo para Instagram, X ou WhatsApp.

**▶ Usar agora:** https://rios-impassiveis.github.io/quadro-a-quadro/

![Quadro a Quadro](og-image.png)

## O que dá para fazer

- **Adicionar imagens do dispositivo:** selecione várias de uma vez, arraste para a página ou cole com Ctrl+V. No celular, o botão abre a galeria.
- **Deixar todos os quadros iguais:** escolha a proporção e as fotos são recortadas automaticamente.
  - 16:9 (TV / YouTube)
  - 1.85:1 (cinema)
  - 2.39:1 (cinemascope)
  - 3:2 (foto, ex.: 1600×1066)
  - 4:3 (filme antigo)
  - Igual à 1ª imagem
- **Escolher o enquadramento:** arraste a foto na prévia, dê zoom com a rodinha do mouse ou com o controle de cada quadro, e clique duas vezes para recentralizar.
- **Legenda clássica:** amarela com contorno preto, quebra de linha automática, várias fontes, cor, tamanho, contorno, sombra e MAIÚSCULAS.
- **Formatos prontos para redes sociais:**

  | Rede | Formato | Tamanho |
  |---|---|---|
  | Instagram | Feed retrato 4:5 | 1080 × 1350 |
  | Instagram | Feed quadrado 1:1 | 1080 × 1080 |
  | Instagram | Stories / Reels 9:16 | 1080 × 1920 |
  | X (Twitter) | Retrato 4:5 | 1080 × 1350 |
  | X (Twitter) | Paisagem 16:9 | 1600 × 900 |
  | WhatsApp | Conversa | 1080 de largura |
  | WhatsApp | Status 9:16 | 1080 × 1920 |
  | Livre | Tirinha | 720, 1280 ou 1920 de largura |

- **Exportar:** baixe em PNG ou copie a imagem para colar direto numa conversa.
- **Cortar barras pretas:** o app remove sozinho as tarjas de prints de vídeo.

## Privacidade

Tudo acontece no seu navegador. As imagens **não são enviadas para nenhum servidor**. O app é um único arquivo HTML, sem dependências e sem rastreamento.

## Rodar no seu computador

Baixe o `index.html` e abra no navegador. Não precisa instalar nada.

## Publicar no GitHub Pages

1. Suba os arquivos deste repositório para a branch `main`.
2. Vá em **Settings → Pages → Build and deployment**.
3. Em **Source**, escolha **Deploy from a branch**.
4. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
5. Em 1 a 2 minutos o site fica no ar em `https://rios-impassiveis.github.io/quadro-a-quadro/`.

> As tags `og:` do `index.html` montam a prévia quando alguém compartilha o link.
